# UniBuzz – web app

The Next.js website for UniBuzz, a private social network for university life — connecting students, clubs, events, campus news, housing, and the student marketplace in one place. It includes the business portal at `/business`. The overview is in the root [README.md](../../README.md); setup, deployment and how each feature is built are in [docs/technical-reference.md](../../docs/technical-reference.md).

```bash
cp .env.example .env.local   # fill in your Supabase URL + anon key
npm run dev                  # from the repository root
```
